spatial_scale:

Definition: The geographic extent over which the study collected and analyzed data, based only on information explicitly stated or strongly implied in the abstract.

Classify the spatial implementation extent of the study — NOT buffer sizes, sampling radii, pixel resolution, temporal scale, or statistical modeling scale.
If the abstract uses vague terms like “region”, “landscape”, or “study area”, interpret based on context:
- If multiple sites or plots are studied across a non-local area → classify as regional.
- If only one park, reserve, or small site is mentioned → classify as local.
If multiple spatial scopes appear, assign the highest applicable and clearly supported category.
Do not classify based on analytical scale or methodological scale.

Precedence hierarchy:
global > continental > national > regional > local

If the geographic extent cannot be determined from the abstract, assign NA.

Allowed levels:
- local
Definition: Study conducted at a limited number of sites within a small area, such as a park, reserve, municipality, or localized landscape. Subnational and site-level studies that do not cover broad regional coverage fall here.
- regional
Definition: Study conducted across multiple sites within a broader ecological or administrative region, across multiple subnational units, or across a defined landscape that spans part of a country but is not nationwide. For broad ecological region terms (e.g., Southeast Asia, Amazon Basin, Congo Basin), classify as regional unless the abstract explicitly states continental-scale coverage or multi-country design.
- national
Definition: Study explicitly conducted across an entire country or clearly described as nationwide. If country-wide coverage is stated, classify it as national regardless of geographic size. If the study explicitly covers an entire country, classify it as national regardless of country size.
- continental
Definition: Study conducted across multiple countries within the same continent or explicitly described as continental-scale.
- global
Definition: Study includes multiple continents, worldwide data, or is explicitly described as global or worldwide.


taxonomy_scope:

Definition: Biological unit of analysis.
If the biological unit of analysis cannot be identified, return NA.

Allowed levels:
- single_species → one focal species
- multi_species → multiple named species analyzed separately
- community → assemblage, guild, or biodiversity metrics


primary_taxonomic_group:

Definition: The main taxonomic group being studied.
If all studied species belong to the same major group → return that group.
If species belong to multiple major groups → return multi_taxa.
If the primary taxonomic group being studied cannot be identified, return NA.

Allowed levels:
- mammal
- bird
- reptile
- amphibian
- fish
- invertebrate
- multi_taxa


study_approach:

Definition: Primary research design based on whether the study includes active manipulation.
If there is insufficient methodological information, return NA.

Allowed levels:
- observational → empirical field or survey data collected and analyzed with no active manipulation or intervention. Statistical analyses and habitat/species distribution modeling (e.g., regression, GLM, occupancy models, MaxEnt, SDMs) applied to empirical data are still observational.
- experimental → includes deliberate manipulation, treatment vs control design, intervention, before–after impact design, exclusion experiments, or controlled disturbance applied by researchers.
- mixed → includes both observational components and at least one experimental manipulation component.
Important:
Do not classify a study as mixed simply because it uses statistical or distribution modeling. Modeling of empirical data alone remains observational. Mixed requires true experimental manipulation in addition to observational data.


temporal_design:

Definition: Temporal structure of data collection.
If the temporal structure is not explicitly stated in the abstract, return NA.

Allowed levels:
- cross_sectional → data collected during a single defined sampling period or season, even if temporal predictors (e.g., time since disturbance) are used.
- longitudinal → repeated sampling of the same area or population across multiple time points or years.
If the abstract reports a continuous sampling period (e.g., “March 2012 – February 2013”) without indicating repeated temporal blocks, treat it as a single sampling window → cross_sectional.
Do NOT classify as longitudinal solely because the period spans >1 calendar year.
- before_after → explicit comparison of data collected before and after a defined event or intervention.
- mixed → At least two different temporal structures are explicitly present (e.g., before_after + longitudinal, or cross_sectional + longitudinal comparison).
Do NOT assign mixed based on multiple sampling methods alone.

temporal_scale_month:

Integer representing study duration in months if temporal duration is explicitly reported or can be directly calculated from reported sampling dates.
Else → "NA".

General Rules:
1. Only compute duration from explicit temporal information:
   - Reported start AND end dates
   - Reported start AND end years
   - Explicit sampling time span
   - Explicit seasonal periods linked to years
2. Do NOT infer duration from sampling effort metrics:
   - Trap nights
   - Camera days
   - Number of records
   - Number of detections
   - Effort-based metrics
3. If a start time/date is provided without an end time/date, return NA.
4. If duration is given as start year – end year and no months are specified:
   → Assume full calendar years unless otherwise stated.
   Formula:
   Temporal duration (years) = (end_year − start_year + 1)  
   Temporal_scale_month = Temporal duration (years) × 12  
   Example:
   2011–2016 → (2016 − 2011 + 1) × 12 = 72 months
5. If duration is reported in weeks or days:
   → Convert to months by dividing by 30  
   → Round to the nearest whole number  
   If result < 1 month → return 1.
6. Multi-season / Multi-year sampling periods:
   If the abstract reports sampling periods defined by season + multiple consecutive years (e.g., “spring–summer of 2020–2021 and 2021–2022”) AND the study spans distinct yearly sampling cycles
   → Treat the temporal duration as the full span between the earliest reported year and the latest reported year (inclusive).
   Compute:
   Temporal duration (years) = (latest_year − earliest_year + 1)  
   Temporal_scale_month = Temporal duration (years) × 12

============================================================
BINARY ECOLOGICAL VARIABLE DEFINITIONS

Global rules for binary ecological variable definitions:
- Variables are coded based on conceptual meaning, NOT keyword appearance.
- A variable is coded as 1 ONLY if it is a response variable, OR a predictor variable explicitly modeled, OR a primary objective stated in the abstract.
- Descriptive mention, ecological context, or speculation does NOT trigger 1.
- If the abstract merely mentions a concept without analysis → 0.
- If the concept appears but is not quantitatively evaluated → 0.
- If ambiguous → default to 0.
- Statistical models do NOT auto-trigger ecological variables unless the variable is explicitly analyzed.
- Do not assume that commonly studied variables (e.g., habitat use, abundance, disturbance effects) were analyzed unless explicitly stated.
============================================================

abundance → counts, relative abundance, abundance index.
